# 赛博魔法 · 星尘粒子场

进入游戏后，整块屏幕是一大片由数百颗发光粒子组成的星尘场：粒子自由漂浮、闪烁、
拖着尾迹，近邻之间还有极淡的连线。**没有面板、没有帮助、没有画笔——只有粒子与你的手。**

- **主界面**是一张干净的科技感菜单，**不渲染任何粒子**（粒子循环完全暂停）
- 点击「进入粒子场」后开启摄像头/手势，全屏只剩星尘
- 游戏中按 **ESC**：退出全屏并回到主界面；再次进入无需重新加载模型
- **没有任何鼠标交互**，也不会隐藏系统光标；只认手势
- **食指单指**：把附近的粒子推开，扫过时留下一道尾流
- **拇指 + 食指捏合**：所有粒子被吸向捏合点并旋转成涡流；但它们始终在「挣扎」——
  越靠近核心，挣脱的冲动越强，还会不定时向外猛窜。捏合点永远聚不成一个实心点，
  而是成为一团不断呼吸、旋转、逃逸的星云
- **松开捏合**：粒子带着动量散开，重新回到自由漂移

摄像头画面只用于识别，**绝不显示**；摄像头帧只在当前浏览器内存中交给 MediaPipe 处理，不会上传。

## 1. 运行

```powershell
# 在项目根目录
run_web.bat
```

或手动：

```powershell
.venv\Scripts\python.exe web_server.py
```

脚本会启动一个只监听 `127.0.0.1` 的静态服务器（默认 `http://127.0.0.1:8765/`），
并自动打开默认浏览器。端口被占用会自动往后找。

> **不要直接双击 `web/index.html`。** 浏览器只在 `https` 或 `localhost/127.0.0.1`
> 下允许使用摄像头。

### 环境要求

- Chrome / Edge（推荐最新版），需要 WebGL、WebAssembly SIMD
- 一个摄像头
- 不需要联网：MediaPipe 运行时、模型、页面全部内置在 `web/` 里

## 2. 交互

### 手势

| 手势 | 效果 |
| --- | --- |
| 只伸食指 | 指尖产生一个推力场，把星尘推开、扫出尾流 |
| 拇指 + 食指捏合 | 出现聚拢核心，所有粒子被拉向捏合点并旋转 |
| 保持捏合 | 粒子继续聚拢，但挣脱越来越剧烈，星云在呼吸、逃逸 |
| 松开捏合 | 冲击波散开，粒子带着惯性回到自由漂移 |
| 手离开画面 | 一切回归自然 |

### 键盘

| 按键 | 功能 |
| --- | --- |
| `ESC` | 退出全屏并返回主界面（不会关闭摄像头页面） |
| `F` | 全屏切换 |

> 游戏不接管鼠标，也不隐藏光标；鼠标只用来点击主界面的按钮。

## 3. 粒子场的行为（物理设计）

每颗粒子同时受这几股力：

| 力 | 作用 |
| --- | --- |
| 自由游走 | 沿缓慢旋转的方向漂移 + 随机抖动（它们生来想漂） |
| 回家弹性 | 被拽离「老家」越远，想回去的拉力越强——这就是挣脱的根源 |
| 捏合吸引 | 距离衰减的向心拉力，远处也能感到（所有粒子都动） |
| 旋涡 | 核心附近的切向力，让聚拢变成旋转的涡流 |
| 核心排斥 | 软核：越靠近捏合点顶得越狠，粒子悬停在核心外，绝不塌成一点 |
| 挣脱冲动 | 离核心越近憋得越快，憋满就反向顶 + 不定时向外猛窜 |
| 指尖推开 | 半径内的粒子被推远，附带一点切向扰动形成尾流 |

所有力都作用在**同一批**粒子上，因此捏合时你会看到：远处星尘缓缓漂来，
中层粒子减速观望，近处粒子高速旋转、挣扎逃逸，再被拉回——整体是一团活的星云。

### 视觉细节

- 粒子有**远近层次**：近处更大更亮、漂移更快，远处更小更暗，形成空间纵深
- 少量粒子带**星芒十字**，增加精致感
- 挣脱瞬间粒子会**闪亮**并拖出一条暖色流星尾迹，让“挣扎”看得见
- 靠近捏合核心的粒子颜色会**升温**，偏向琥珀色
- 捏合核心是**旋转的锥形能量环 + 反向虚线轨道 + 三颗轨道亮点 + 外圈射线 + 脉冲冲击环**
- 核心附近的粒子连线会变亮，像被能量撕开的引力网

## 4. 调参

全部参数在 `web/js/config.js` 的 `FIELD` 里：

| 参数 | 含义 | 调整建议 |
| --- | --- | --- |
| `attractStrength` | 聚拢拉力 | 调大远处粒子来得更快 |
| `escapeGain` / `escapeMax` | 挣脱冲动的积累与力度 | 调大越聚越憋、窜得更凶 |
| `escapeImpulse` / `escapeInterval` | 随机挣脱冲量 | 调大 / 调密 |
| `coreK` / `coreRadius` | 软核排斥 | 调大让星云更蓬松 |
| `homeK` | 回家弹性 | 调大让它们更快散回原位 |
| `swirl` / `tangentDamp` | 旋涡与近核切向阻尼 | 调大更转，但太大不容易聚拢 |
| `pushStrength` / `pushRadius` | 指尖推开 | 按喜好调 |
| `density` / `minCount` / `maxCount` | 粒子数量 | 低配机器调小 |
| `trailFade` / `streakMaxLen` | 尾迹长度 | 调小拖尾更长 |
| `linkDistance` / `linkAlpha` | 近邻连线 | 调小网络更稀疏 |
| `hotRadius` / `hotMix` | 捏合核心附近的升温范围与程度 | 按喜好调 |

## 6. 调试模式

| URL | 作用 |
| --- | --- |
| `?demo=1` | 不开摄像头自动演示：自由漂浮 → 指尖扫过 → 捏合聚拢 → 持续挣扎 |
| `?selftest=1` | 初始化 MediaPipe 并在空白帧上跑一次推理，结果写到页面和标题 |
| `?autostart=1` | 无点击直接进入摄像头（配合 Chrome 假摄像头做自动化验证） |
| `?preview=1` | 右下角显示摄像头预览 + 手部骨架 + 画板可见区域 |
| `?delegate=CPU` | 强制 CPU 推理（GPU 异常时排查用；默认 auto：GPU → CPU） |
| `?mirror=0` | 关闭镜像（默认像照镜子） |
| `?cdn=0` | 强制用本地 wasm 与模型（GitHub Pages 线上部署时才需要） |

浏览器控制台里还有一个调试句柄：

```js
__cyberMagic.system.count          // 当前粒子数
__cyberMagic.system.attractor      // 当前捏合核心
__cyberMagic.state.pinchStrength   // 聚拢力度 0..1
__cyberMagic.state.mode            // gate / camera / demo / selftest
__cyberMagic.state.raf             // 0 表示粒子循环已暂停（主界面）
```

自检成功时页面标题会变成 `SELFTEST_OK`，失败为 `SELFTEST_FAIL`，页面上的
`#selftest-result` 会输出耗时和后端（GPU / CPU）。

## 8. 常见问题

**Q：主界面为什么没有粒子？**
A：这是刻意的。主界面是干净的菜单，粒子循环完全暂停（`state.raf === 0`，
画布不可见）；进入后粒子场才启动，也保证主界面不抢 GPU。

**Q：游戏中怎么退出？**
A：按 `ESC`。会退出全屏并回到主界面，摄像头保持就绪；再点「继续粒子场」立即恢复，
不会重新加载模型。按 `F` 只切换全屏，不返回菜单。

**Q：屏幕上只有粒子在漂，没有反应？**
A：摄像头已启动但还没识别到手。把手完整放进画面、只伸食指（推开）或拇指食指捏合
（聚拢）。不确定画面取景时打开 `?preview=1` 看右下角的摄像头预览和虚线框。

**Q：鼠标为什么没有用？**
A：这个作品只认手势，鼠标不参与游戏，系统光标也保持正常显示。

**Q：捏合聚得太紧 / 太散？**
A：调 `web/js/config.js` 里的 `coreK`、`coreRadius`、`escapeGain`（见第 4 节）。

**Q：粒子太少 / 太卡？**
A：调 `FIELD.density` 与 `maxCount`；低配机器也可以把浏览器窗口调小。

**Q：摄像头打不开？**
A：检查是否被会议 / 直播 / 相机软件占用、笔记本隐私开关是否打开。

**Q：端口 8765 被占用？**
A：`web_server.py` 会自动往后找可用端口，终端里会打印实际地址。

## 9. 与桌面版的关系

- 桌面版（`main.py`，Pygame + OpenCV）是旧的手势画板 Demo，保留不动。
- 网页版重制为**星尘粒子场**：没有画笔、没有面板、没有 HUD。
- 两者共用同一套手部模型、手势判定与调色板审美，手感一致。
- MediaPipe 运行时和模型的来源、版本、升级方法见
  [vendor/mediapipe/README.md](vendor/mediapipe/README.md) 和
  [assets/README.md](assets/README.md)。
